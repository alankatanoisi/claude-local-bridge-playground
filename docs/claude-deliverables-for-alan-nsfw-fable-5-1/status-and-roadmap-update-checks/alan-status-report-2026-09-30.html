Thread 1. The Starlark host (the one you remember wanting)

What it is, in plain words. A separate laboratory folder, starlark-host/, that tests one narrow idea. A "planner" model writes a tiny program in Starlark (a restricted, Python-looking language used by the Bazel build tool). That program cannot touch files, the network, or other models. Its only possible output is a list of inert job descriptions. A small Go program runs it, and a Node host then validates every job, decides which real worker models to call, meters the dollars, fans the jobs out, records every step in an append-only ledger, and finally synthesizes one answer. The doctrine written on 2026-08-06 and repeated in every handoff since is "code as plan, not code as action": the model proposes, your host disposes.

Why you wanted it. It lets you study multi-model fan-out (which model should plan, which should work, how to budget, how to survive a crash or a Ctrl-C) in a form where the generated code cannot bypass the runner's permission controls. That was the exact worry the orchestration review raised about "CodeAct"-style agents that execute model-written code directly.

What it has produced. Real, measured results: the cheapest model (Haiku 4.5) was the best planner across 25 paid trials; Sonnet 5 was the only reliable worker across 20; verbosity, not capability, was the dominant failure mode. A durable, interruptible, resumable campaign system that was live-verified for about $0.18 across three real kill-and-resume runs. A fidelity review that found synthesized reports are not trustworthy as code-audit findings (of 101 assertions, 24 were contradicted by the evidence). That last one is a genuine research finding about model-written summaries.

Where it stands today. On main, the lab is healthy: 128 of 128 tests pass with zero skips because Go and the evaluator are now installed on this laptop. Recommendations R1 through R14 are all either done or deliberately parked. Glossary

Bridge
The VS Code extension (or, since 09-26, a standalone process) that turns your Claude Code login into a local HTTP endpoint at localhost:11437. "Transport plumbing"; rarely edited on purpose.
Runner
The local coding-agent loop: prompt, model reply, tool call, tool result, repeat. The thing most of the work is about.
Handoff
A dated Markdown file written by one agent for the next, recording what was done, verified, skipped, and left open. The repo root holds 46 of them.
Thermo-nuclear review
The name this project uses for Cursor's deep invariant review of a landed range of commits: severity-ranked findings plus a "not bugs, do not fix" list.
Commit hash
The short code (like 84dd73a) git uses to name one saved change. You can paste it into GitHub's search box or run git show 84dd73a in Terminal inside the repo folder.
Branch
A named line of commits. main is the one you normally work on. Other branches (like codex/starlark-resume-2020-2026-09-26) hold work that has not been merged into main.
Worktree
A second checked-out copy of the repo in another folder, sharing the same history. There are six on this laptop.
Pull request (PR)
A GitHub request to merge one branch into another, with a place for review. Two are open: #26 and #21.
P0 / P1 / P2
Priority labels. In this repo P0-01 to P0-12 is a specific closed series; "FD-xx" and "HE-xx" are other series; the 08-10 review uses P0/P1/P2 as generic priorities. Always read the series letter.
Golden eval
A recorded scenario the runner must reproduce; "terminal-state checklist" cases check the end state instead of the exact path.
Ledger
An append-only record of every step in a run, used for crash recovery and forensics. Session ledgers live under ~/.bridge-runner; Starlark campaign ledgers under ~/.bridge-runner/campaigns.
Fingerprint
The set of request headers that make the bridge's calls look like Claude Code's own. Pinned to a Claude Code version; refreshed by a scheduled check.
Starlark
A small, restricted, Python-like language from the Bazel build tool. Chosen because programs in it cannot do anything except compute values.
ACP
Agent Client Protocol: newline-delimited JSON over standard input/output between an editor and an agent program.
OAuth token
A login credential string. Claude Code's begin with sk-ant-oat01-. Treat like a password.
STALLED vs PARKED
Parked means someone wrote down "we are not doing this now" and usually why. Stalled means it was named and then simply never mentioned again. Only stalled items are scope creep in the strict sense.
