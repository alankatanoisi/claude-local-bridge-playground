First live exercise of the round-3 coordinator work: budget leasing (_spawnLeasedWorker) and dependency-batched research fan-out (--research-plan), previously verified only by unit tests. Four read-only research lanes over this repo, run twice with identical prompts and budgets (--budget-input-tokens 400000 --budget-output-tokens 20000): once dependency-free (one batch of 4), once dep-chained (four batches of 1). Phases research,synthesize only — no repo edits.

Speedup 4.13× at token parity. Input tokens are byte-identical across arms because the read-only research paths are deterministic — fan-out buys wall clock, not token savings. Per-worker wall time was ~12–14 s in both arms: essentially ideal 4-way overlap. The budget invariant held in the field: 8 distinct leases across the two runs, each concurrent sibling got the unleased remainder ÷ batch size (100k/5k each), every lease released and reconciled, budget.used equal to summed child usage.

The failed first attempt is data too. With library defaults (maxSteps: 6, worker output hard-capped at 2,000 tokens/request) all four workers died at a ceiling — three max_steps, one model_max_tokens — burning 91,702 input tokens for zero usable summaries, more than the successful run cost (58,568). With fan-out, a ceiling misconfiguration multiplies by the node count. Size ceilings before fanning out.

Findings

ID Finding
A3-F1 The coordinator CLI exits 1 for any run without an execute phase, so research-only runs look like failures to shell scripts despite error: null.
A3-F2 Worker children are pinned to the runner CLI default of 2,000 output tokens/request; no plan or inherit knob raises it (live model_max_tokens failure observed). The coordinator's --max-tokens only reaches the execute-phase kernel.
A3-F3 Default maxSteps: 6 is too small for broad research prompts on this repo (3/4 live workers hit it); per-node maxSteps in the plan is the practical knob.
A3-F4 The broker meters uncached input/output only; live workers also reported 4k–51k cache_read_input_tokens each, so real upstream cost diverges from metered cost.
