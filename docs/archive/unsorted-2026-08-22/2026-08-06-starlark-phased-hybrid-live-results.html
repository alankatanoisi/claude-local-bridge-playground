What Field Conditions Exposed

1

Disclose policy, then enforce it

The first prompt omitted numeric bounds. The host rejected out-of-policy descriptors. Exact limits are now stated to the model and still enforced locally.

2

Python-shaped is not Python-identical

Some planners used adjacent Python strings. Starlark required explicit +; the bounded repair turn corrected them.

3

Worker output is a protocol

A 1,200-token ceiling caused wholesale JSON truncation. A larger envelope plus host-enforced compact field limits produced valid artifacts.

4

HTTP 200 is not semantic success

Refusal and max_tokens responses now create explicit partial states rather than false completion.

5

Controls differ by model family

Haiku does not accept newer effort or adaptive-thinking fields. The adapter now omits unsupported controls before dispatch.

6

Validated fields must drive execution

Job timeout descriptors are now connected to actual network abort signals, not merely checked for shape.

7

Campaign budgeting is still unfinished

One process is protected against concurrent overbooking. Separate commands still require manually reduced allowances until a durable atomic campaign ledger exists.
