Claude Code Fingerprint Automation

A conservative weekly checker, guarded patch preparer, and durable project ledger for the local bridge playground.

This is personal, unsanctioned research. It does not establish Anthropic approval. The automation never uses a real OAuth token, never calls Anthropic for capture, and never commits, pushes, or merges.

Three explicit modes

Check

npm run fingerprint:check

Captures stable localhost-only identity values, compares them, and writes reports. It does not edit source.

Due

npm run fingerprint:due

Runs a real check only when the last successful check is at least seven days old.

Prepare

npm run fingerprint:prepare

May create a dated patch branch and update one manifest, but only from a clean, current repository.

The child process uses a temporary config directory, safe mode, no tools, and a localhost Anthropic base URL. Request bodies are drained but never stored. Authorization, sessions, retries, timeouts, billing values, and account metadata are never placed in a report.

Records

Detailed owner-only records are kept outside Git:

~/.bridge-runner/fingerprint-checks/

One concise, append-only entry per real run is created in the project:

docs/automation-ledger/fingerprint-checks/YYYY-MM-DDTHH-mm-ss-check.md

A scheduled ledger entry is intentionally uncommitted. It makes the repository dirty, so prepare mode will wait until a human reviews and handles the current work.

Manual first run

Open Terminal and run:

cd /Users/alanman/Developer/claude-local-bridge-playground
npm run fingerprint:check

Success prints the action, private report path, and project ledger path. Drift appears as report only; check mode still does not edit the fallback.

Weekly schedule with catch-up

The tracked LaunchAgent template prefers Monday at noon, runs the cheap due wrapper every four hours, and checks at login. The due wrapper is authoritative: it exits immediately unless seven days have passed. A missed Monday run becomes one catch-up run when the Mac is next available.

The LaunchAgent template exists in the repo, but it has not been installed or loaded.

Install only after explicit approval

mkdir -p /Users/alanman/Library/LaunchAgents
cp -n /Users/alanman/Developer/claude-local-bridge-playground/docs/automation-ledger/com.alanman.claude-fingerprint-check.plist /Users/alanman/Library/LaunchAgents/
plutil -lint /Users/alanman/Library/LaunchAgents/com.alanman.claude-fingerprint-check.plist
launchctl bootstrap gui/$(id -u) /Users/alanman/Library/LaunchAgents/com.alanman.claude-fingerprint-check.plist

plutil should print OK. A successful bootstrap is normally silent.

Turn the schedule off

launchctl bootout gui/$(id -u)/com.alanman.claude-fingerprint-check

Review boundary

When drift is reported, review the records, resolve existing local changes, run prepare, inspect the generated branch and validation results, and only then decide whether to commit or push. The machine-editable header source is src/claude-code-fingerprint-fallback.json. Older body-level fallback system blocks remain separate and are never auto-updated.
